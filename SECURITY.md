# Security Policy

## Reporting a Vulnerability

If you think you have found a security vulnerability in Credo, please report it privately through [GitHub Security Advisories](https://github.com/openwallet-foundation/credo-ts/security/advisories/new). Do not open a public issue, pull request or discussion for it.

Include a description of the issue, the affected packages and versions, and steps to reproduce it if you can. The maintainers will follow up in the advisory, work on a fix, and publish the advisory once a patched release is available.
